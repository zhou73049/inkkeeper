配置说明

打印机连接方式

通过环境变量 PRINTER_CONNECTION 设置:

cups (默认)
使用 CUPS 打印系统。需挂载宿主机的 CUPS socket 和配置: 
-v /var/run/cups/cups.sock:/var/run/cups/cups.sock:ro
-v /etc/cups:/etc/cups:ro
network
直连网络打印机 (端口 9100)。需设置 PRINTER_IP
script
使用自定义打印脚本。需设置 PRINT_SCRIPT 路径，脚本接收参数: 脚本路径 <图片文件> <任务名>

USB 打印机

如需直接访问 USB 打印机，在 docker-compose.yml 中添加:

devices:
  - /dev/usb/lp0:/dev/usb/lp0
# 或者使用 privileged: true
